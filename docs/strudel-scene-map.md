# Strudel Scene Map and Outreach Targets

Research date: 2026-05-17

Project context: `voice-strudel` is a local proof of concept for speaking musical instructions, previewing the model's interpretation, and applying approved changes as Strudel code in the browser through `@strudel/web`.

## Read This First

The Strudel scene is not primarily an X/Twitter scene. The core community is centered around Codeberg, the Uzulang/Tidal Discord, the Uzu forum, Mastodon instances such as `social.toplap.org` and `post.lurk.org`, TOPLAP/Algorave networks, and local live-coding nodes. X is useful for reaching adjacent developer, AI, and electronic-music audiences, but the most credible Strudel-native route is to post in the community channels first and tag lightly on X.

Also important: Strudel's contributor docs say LLM-related discussion should stay in the Discord `#llm-chat` / `#llm-share` channels and the Uzu forum has an "LLM Corner". Position this as an external experiment built with Strudel, not as a proposed LLM feature for Strudel core.

## Launch Sequence

1. Community-first soft post:
   - Post in Uzu forum `LLM Corner` and/or Strudel Discord `#llm-share`.
   - Include a 20-45s video, source link, and AGPL/source note.
   - Ask: "Is this useful as an external Strudel experiment? Any concerns before wider sharing?"

2. X launch post:
   - Keep tags sparse: `@tidalcycles @algorave @OpenAIDevs`.
   - Use hashtags: `#strudel #tidalcycles #algorave #livecoding #creativecoding #webaudio #RealtimeAPI`.
   - Mention the human approval step: the model proposes code, the performer accepts/refuses.

3. Mastodon launch:
   - Tag `@strudel@social.toplap.org`, `@tidalcycles@post.lurk.org`, and `@yaxu@post.lurk.org` only if the post is respectful and source-first.
   - Mastodon will likely matter more than X for core Strudel people.

4. Dev/AI angle:
   - Post a second clip focused on architecture: OpenAI Realtime over WebRTC, local Express bridge, `@strudel/web`.
   - Tag `@OpenAIDevs` and possibly Tambo/DJ Opus people if comparing interaction modes.

5. Music/creative angle:
   - Post a performance clip with no architecture diagram.
   - Tag `@algorave`, local live-coding groups, and relevant artists only if their work is directly referenced or credited.

6. Longer write-up:
   - Write a short blog/README section: "Voice as a controller, not a replacement for live coding."
   - Include license/source notes and the approval flow to avoid "AI replacing performers" framing.
